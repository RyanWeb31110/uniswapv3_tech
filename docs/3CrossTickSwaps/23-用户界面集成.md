## 二、添加流动性对话框

### 2.1 需求分析

在之前的实现中，我们使用硬编码的方式添加流动性：

```javascript
// ❌ 旧实现：硬编码的流动性参数

await pool.mint(tickLower, tickUpper, amount);
```

这种方式有明显的局限性：
- 无法选择自定义价格区间
- 不能根据市场情况调整参数

### 2.3 价格到 Tick 的转换

这是关键的一步：**用户输入的是价格，但合约需要的是 Tick 索引**。

让我们使用 Uniswap V3 SDK 来完成转换：

```javascript
import { encodeSqrtRatioX96, TickMath } from '@uniswap/v3-sdk';

/**
 * 将价格转换为 sqrtPriceX96
 * @param price - 价格（例如：5000 表示 1 ETH = 5000 USDC）
 * @returns sqrtPriceX96 格式的价格
 */
const priceToSqrtP = (price) => {
  // encodeSqrtRatioX96 接受两个数量，计算它们的比率
  // 传入 price 和 1，得到 price:1 的比率
  return encodeSqrtRatioX96(price, 1);
};

/**
 * 将价格转换为 Tick 索引
 * @param price - 价格
 * @returns Tick 索引
 */
const priceToTick = (price) => {
  const sqrtP = priceToSqrtP(price);
  return TickMath.getTickAtSqrtRatio(sqrtP);
};
```

**工作原理解释**：

1. **encodeSqrtRatioX96 函数**：
   ```javascript
   // 输入：price = 5000（表示 1 ETH = 5000 USDC）
   const sqrtP = encodeSqrtRatioX96(5000, 1);
   
   // 内部计算：
   // ratio = 5000 / 1 = 5000
   // sqrtRatio = sqrt(5000)
   // sqrtPriceX96 = sqrtRatio * 2^96
   ```

2. **TickMath.getTickAtSqrtRatio 函数**：
   ```javascript
   // 输入：sqrtPriceX96
   const tick = TickMath.getTickAtSqrtRatio(sqrtP);
   
   // 内部计算：
   // price = (sqrtPriceX96 / 2^96)^2
   // tick = log_1.0001(price)
   ```

### 2.4 计算滑点保护参数

添加流动性时，我们需要设置最小接受数量以防止滑点：

```javascript
/**
 * 根据滑点容忍度计算最小金额
 * @param desiredAmount - 期望的代币数量
 * @param slippagePercent - 滑点容忍度（百分比）
 * @returns 最小可接受的代币数量
 */
const calculateMinAmount = (desiredAmount, slippagePercent) => {
  // 将百分比转换为基点（basis points）
  // 0.5% = 0.5 * 100 = 50 基点
  const slippageBps = slippagePercent * 100;

  // 计算最小金额
  // minAmount = desiredAmount * (10000 - slippageBps) / 10000
  return desiredAmount.mul(10000 - slippageBps).div(10000);
};
```

**示例计算**：

```javascript
// 假设：
// - 期望投入 1 ETH
// - 滑点容忍度 0.5%

const amount0Desired = ethers.utils.parseEther("1.0");
const slippage = 0.5;

const amount0Min = calculateMinAmount(amount0Desired, slippage);

// 结果：
// amount0Min = 1 ETH * (10000 - 50) / 10000
//            = 1 ETH * 0.995
//            = 0.995 ETH

// 含义：最少接受 0.995 ETH 的流动性，如果实际需要超过 1.005 ETH，交易会失败
```

### 2.5 完整的添加流动性逻辑

将所有部分整合在一起：

```javascript
// AddLiquidityDialog.jsx

import { encodeSqrtRatioX96, TickMath } from '@uniswap/v3-sdk';
import { ethers } from 'ethers';

function AddLiquidityDialog({ pool, onClose, onConfirm }) {
  const [lowerPrice, setLowerPrice] = useState('');
  const [upperPrice, setUpperPrice] = useState('');
  const [amount0, setAmount0] = useState('');
  const [amount1, setAmount1] = useState('');
  const [slippage, setSlippage] = useState(0.5);

  /**
   * 处理添加流动性
   */
  const handleAddLiquidity = async () => {
    try {
      // 步骤 1: 将用户输入的价格转换为 Tick
      const lowerTick = priceToTick(parseFloat(lowerPrice));
      const upperTick = priceToTick(parseFloat(upperPrice));

      console.log(`价格范围: ${lowerPrice} - ${upperPrice}`);
      console.log(`Tick 范围: ${lowerTick} - ${upperTick}`);

      // 步骤 2: 解析代币数量
      const amount0Desired = ethers.utils.parseEther(amount0);
      const amount1Desired = ethers.utils.parseUnits(amount1, 6); // USDC 是 6 位小数

      // 步骤 3: 计算滑点保护的最小金额
      const slippageBps = slippage * 100; // 0.5% -> 50 基点
      const amount0Min = amount0Desired.mul(10000 - slippageBps).div(10000);
      const amount1Min = amount1Desired.mul(10000 - slippageBps).div(10000);

      console.log(`期望金额: ${amount0} ETH, ${amount1} USDC`);
      console.log(`最小金额: ${ethers.utils.formatEther(amount0Min)} ETH, ${ethers.utils.formatUnits(amount1Min, 6)} USDC`);

      // 步骤 4: 调用合约添加流动性
      const tx = await pool.mint({
        tickLower: lowerTick,
        tickUpper: upperTick,
        amount0Desired: amount0Desired,
        amount1Desired: amount1Desired,
        amount0Min: amount0Min,
        amount1Min: amount1Min,
        recipient: await pool.signer.getAddress(),
        deadline: Math.floor(Date.now() / 1000) + 60 * 20, // 20 分钟后过期
      });

      console.log('交易已提交:', tx.hash);

      // 步骤 5: 等待交易确认
      const receipt = await tx.wait();
      console.log('交易已确认:', receipt.transactionHash);

      // 通知父组件
      onConfirm(receipt);
      onClose();

    } catch (error) {
      console.error('添加流动性失败:', error);
      alert(`添加流动性失败: ${error.message}`);
    }
  };

  // 价格转换辅助函数
  const priceToSqrtP = (price) => encodeSqrtRatioX96(price, 1);
  const priceToTick = (price) => TickMath.getTickAtSqrtRatio(priceToSqrtP(price));

  return (
    // ... JSX 界面代码（如 2.2 节所示）
    <div className="dialog-overlay">
      {/* ... */}
      <button onClick={handleAddLiquidity}>确认添加</button>
    </div>
  );
}

export default AddLiquidityDialog;
```

### 2.6 关键要点总结

添加流动性对话框的核心流程：

```
用户输入价格
    ↓
转换为 sqrtPriceX96 (使用 encodeSqrtRatioX96)
    ↓
转换为 Tick 索引 (使用 TickMath.getTickAtSqrtRatio)
    ↓
计算滑点保护的最小金额
    ↓
调用合约的 mint 函数
    ↓
等待交易确认
```

## 三、交换滑点容忍度

### 3.1 滑点保护的重要性

在执行代币交换时，价格可能会在交易提交和确认之间发生变化。如果没有滑点保护，用户可能会在不利的价格下完成交易。

**示例场景**：

```
1. 用户想用 1 ETH 兑换 USDC
2. 预期价格：1 ETH = 5000 USDC
3. 提交交易后，价格变化：1 ETH = 4900 USDC
4. 没有滑点保护：用户只得到 4900 USDC（损失 100 USDC）
5. 有滑点保护（0.5%）：交易会回滚，保护用户
```

### 3.3 使用 Quoter 计算限价

在执行交换之前，我们需要：

1. 调用 Quoter 合约估算输出金额和交换后价格
2. 根据滑点容忍度计算限价

```javascript
import { ethers } from 'ethers';

/**
 * 使用 Quoter 估算交换结果
 */
const quoteSwap = async (quoterContract, amountIn, zeroForOne) => {
  try {
    // 调用 Quoter 合约的 quote 函数
    const result = await quoterContract.callStatic.quote({
      pool: poolAddress,
      amountIn: ethers.utils.parseEther(amountIn),
      zeroForOne: zeroForOne, // true: ETH -> USDC, false: USDC -> ETH
      sqrtPriceLimitX96: 0,   // 0 表示无限价（仅用于估算）
    });

    // Quoter 返回三个值
    const amountOut = result.amountOut;           // 预估输出金额
    const sqrtPriceX96After = result.sqrtPriceX96After; // 交换后价格
    const tickAfter = result.tickAfter;           // 交换后 Tick

    return {
      amountOut,
      sqrtPriceX96After,
      tickAfter,
    };
  } catch (error) {
    console.error('报价失败:', error);
    throw error;
  }
};
```

### 3.4 计算滑点保护的限价

关键逻辑：**根据 Quoter 返回的价格和滑点容忍度计算限价**。

```javascript
/**
 * 计算滑点保护的限价
 * @param sqrtPriceX96After - Quoter 返回的交换后价格
 * @param slippagePercent - 滑点容忍度（百分比）
 * @param zeroForOne - 交换方向
 * @returns 限价（sqrtPriceLimitX96 格式）
 */
const calculateLimitPrice = (sqrtPriceX96After, slippagePercent, zeroForOne) => {
  // 将滑点转换为基点
  const slippageBps = slippagePercent * 100;

  // 根据交换方向计算限价
  if (zeroForOne) {
    // 卖出 token0 买入 token1
    // 价格下降对用户不利，所以限价是"不低于"
    // limitPrice = priceAfter * (1 - slippage%)
    return sqrtPriceX96After.mul(10000 - slippageBps).div(10000);
  } else {
    // 卖出 token1 买入 token0
    // 价格上升对用户不利，所以限价是"不高于"
    // limitPrice = priceAfter * (1 + slippage%)
    return sqrtPriceX96After.mul(10000 + slippageBps).div(10000);
  }
};
```

**为什么要根据方向区分？**

让我们用一个例子理解：

```
场景 1：卖出 ETH 买入 USDC (zeroForOne = true)
- 当前价格：1 ETH = 5000 USDC
- 预估交换后：1 ETH = 4990 USDC（价格下降）
- 滑点 0.5%，限价 = 4990 * (1 - 0.005) = 4965 USDC
- 含义：如果交换过程中价格低于 4965 USDC，交易回滚

场景 2：卖出 USDC 买入 ETH (zeroForOne = false)
- 当前价格：1 ETH = 5000 USDC
- 预估交换后：1 ETH = 5010 USDC（价格上升）
- 滑点 0.5%，限价 = 5010 * (1 + 0.005) = 5035 USDC
- 含义：如果交换过程中价格高于 5035 USDC，交易回滚
```

### 3.5 完整的交换流程

将所有部分整合：

```javascript
// SwapInterface.jsx

import { ethers } from 'ethers';
import { useEffect, useState } from 'react';

function SwapInterface({ pool, quoter }) {
  const [amountIn, setAmountIn] = useState('');
  const [amountOut, setAmountOut] = useState('');
  const [slippage, setSlippage] = useState(0.5);
  const [limitPrice, setLimitPrice] = useState(null);
  const [quoteData, setQuoteData] = useState(null);

  /**
   * 当输入金额变化时，自动调用 Quoter 估算输出
   */
  useEffect(() => {
    if (!amountIn || parseFloat(amountIn) <= 0) {
      setAmountOut('');
      setLimitPrice(null);
      return;
    }

    const fetchQuote = async () => {
      try {
        // 调用 Quoter 估算
        const result = await quoter.callStatic.quote({
          pool: pool.address,
          amountIn: ethers.utils.parseEther(amountIn),
          zeroForOne: true, // ETH -> USDC
          sqrtPriceLimitX96: 0,
        });

        // 保存完整的报价数据
        setQuoteData(result);

        // 格式化输出金额（USDC 是 6 位小数）
        const amountOutFormatted = ethers.utils.formatUnits(
          result.amountOut,
          6
        );
        setAmountOut(amountOutFormatted);

        // 计算限价
        const limit = calculateLimitPrice(
          result.sqrtPriceX96After,
          slippage,
          true
        );
        setLimitPrice(limit);

      } catch (error) {
        console.error('报价失败:', error);
        setAmountOut('错误');
      }
    };

    // 防抖：500ms 后执行
    const timer = setTimeout(fetchQuote, 500);
    return () => clearTimeout(timer);
  }, [amountIn, slippage]);

  /**
   * 执行交换
   */
  const handleSwap = async () => {
    if (!quoteData || !limitPrice) {
      alert('请先输入金额');
      return;
    }

    try {
      console.log('执行交换...');
      console.log('输入金额:', amountIn, 'ETH');
      console.log('预估输出:', amountOut, 'USDC');
      console.log('限价:', limitPrice.toString());

      // 调用池子合约的 swap 函数
      const tx = await pool.swap(
        await pool.signer.getAddress(),  // recipient
        true,                             // zeroForOne
        ethers.utils.parseEther(amountIn), // amountSpecified
        limitPrice,                       // sqrtPriceLimitX96
        '0x'                              // data
      );

      console.log('交易已提交:', tx.hash);

      // 等待确认
      const receipt = await tx.wait();
      console.log('交易已确认:', receipt.transactionHash);

      alert(`交换成功！获得 ${amountOut} USDC`);

      // 清空输入
      setAmountIn('');
      setAmountOut('');

    } catch (error) {
      console.error('交换失败:', error);
      alert(`交换失败: ${error.message}`);
    }
  };

  /**
   * 计算滑点保护的限价
   */
  const calculateLimitPrice = (sqrtPriceX96After, slippagePercent, zeroForOne) => {
    const slippageBps = slippagePercent * 100;

    if (zeroForOne) {
      // 卖出 token0，不希望价格过低
      return sqrtPriceX96After.mul(10000 - slippageBps).div(10000);
    } else {
      // 卖出 token1，不希望价格过高
      return sqrtPriceX96After.mul(10000 + slippageBps).div(10000);
    }
  };

  return (
    <div className="swap-container">
      {/* ... 界面代码（如 3.2 节所示） */}
      <button onClick={handleSwap}>交换</button>
    </div>
  );
```

```jsx
// App.jsx

import React, { useState, useEffect } from 'react';

import SwapInterface from './components/SwapInterface';

// 合约 ABI 和地址
import PoolABI from './abis/UniswapV3Pool.json';
import QuoterABI from './abis/Quoter.json';

const POOL_ADDRESS = '0x...';   // 部署的池子合约地址
const QUOTER_ADDRESS = '0x...'; // 部署的 Quoter 合约地址

function App() {
  const [provider, setProvider] = useState(null);
  const [signer, setSigner] = useState(null);
  const [pool, setPool] = useState(null);

        <h1>Uniswap V3 交易界面</h1>

        <SwapInterface pool={pool} quoter={quoter} />

            onClose={() => setShowAddLiquidity(false)}
            onConfirm={(receipt) => {
              console.log('流动性已添加:', receipt);
              alert('流动性添加成功！');
            }}
          />
        )}
      </main>
    </div>
  );
}

export default App;
```

## 六、核心知识点回顾

### 6.1 添加流动性对话框

**关键技术**：
- 📐 使用 `encodeSqrtRatioX96` 将价格转换为 sqrtPriceX96
- 🎯 使用 `TickMath.getTickAtSqrtRatio` 将价格转换为 Tick
- 🛡️ 计算滑点保护的最小金额
- 💼 调用合约 mint 函数

**核心公式**：

```javascript
// 价格 -> sqrtPriceX96
sqrtPriceX96 = encodeSqrtRatioX96(price, 1)

// sqrtPriceX96 -> Tick
tick = TickMath.getTickAtSqrtRatio(sqrtPriceX96)

// 滑点保护
minAmount = desiredAmount * (10000 - slippage * 100) / 10000
```

### 6.2 交换滑点容忍度

**关键技术**：
- 📊 使用 Quoter 合约估算交换结果
- 🎚️ 根据滑点容忍度计算限价
- 🔒 在 swap 函数中使用限价保护

**核心逻辑**：

```javascript
// 获取报价
const { amountOut, sqrtPriceX96After } = await quoter.quote(...)

// 计算限价
if (zeroForOne) {
  // 卖出 token0，限制价格不能太低
  limitPrice = sqrtPriceX96After * (1 - slippage%)
} else {
  // 卖出 token1，限制价格不能太高
  limitPrice = sqrtPriceX96After * (1 + slippage%)
}

// 执行交换
await pool.swap(recipient, zeroForOne, amountIn, limitPrice, data)
```

### 6.3 完整工作流程

**添加流动性流程**：

```
用户输入价格区间和代币数量
    ↓
价格转换为 Tick
    ↓
计算滑点保护参数
    ↓
调用 pool.mint()
    ↓
交易确认
    ↓
界面更新
```

**交换代币流程**：

```
用户输入卖出金额
    ↓
调用 quoter.quote() 估算
    ↓
计算限价
    ↓
用户确认
    ↓
调用 pool.swap() 执行
    ↓
交易确认
    ↓
界面更新
```
